## 使用方法

每个Markdown文件可以单独阅读，也可以按照"核心语法→面向对象→泛型编程"的顺序系统学习。代码示例可以直接复制到IDE中运行和验证。

## 代码环境

- 编译器: g++/clang++ 支持C++11或更高版本
- 开发环境: 推荐使用VS Code + C/C++扩展
- 构建工具: CMake (可选)
